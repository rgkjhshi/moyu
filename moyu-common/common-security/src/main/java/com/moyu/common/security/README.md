## security组件包

### 功能
* 定义数据库表通用基础实体
* 定义通用字段自动填充处理类
* 配置类中添加分页插件配置

### 依赖
本模块需要如下依赖

```xml
<dependencies>
    <!-- spring-security  -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-security</artifactId>
    </dependency>
</dependencies>
```
